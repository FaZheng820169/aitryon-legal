隐私政策

最近更新：2026 年 11 月 · 版本 v8

1. 我们收集你的数据吗

我们不收集任何数据：本应用不设服务器，没有统计、埋点或广告 SDK。你的图片和记录不会传到我们这里，我们手里也没有，更没有能力查看。

你可以在「我的」页面登录华为账号。登录只为一件事：让应用认出「还是你」，好在换机或重装后恢复你已购买的权益。凭证由华为账号服务签发，我们只在本机保存一个不含手机号、不含昵称头像的匿名标识，不上传任何地方，也不用于其他用途。不登录不影响任何功能。

有两件事要说清楚：你添加的图片和生成记录会存在手机本地（见第 3 条）；图片会由手机直接发给服务商（见第 2 条）。两件都不经过我们。

唯一例外是购买会员时的支付与订单，那由华为应用市场处理，我们同样拿不到（见第 7 条）。

2. 图片去了哪里

点「开始试衣」时，人像和服装两张图由本机直接发送给你在「我的」里选定的服务商接口，请求里带着你填写的 API Key。这条链路不经过我们的服务器。服务商如何存储、留存、使用这些图片，适用它自己的隐私政策——建议你先查阅，再决定是否添加图片。

3. 本机存了什么

已选的图片、试衣记录、模型配置（含 API Key）、条款同意状态，以及登录后保存的账号匿名标识，都保存在你手机的本地存储里（应用沙箱与首选项）。

API Key 是明文保存在本机的，没有额外加密——请不要在共用设备上填写自己的 Key，用完请及时删除。

卸载应用会清除上面这些记录和配置；已经保存进相册的图片不受影响，需要你在相册里自行清理。

「清空试衣记录」会同时删除本机记录和已经写进相册的那一份副本。

4. 权限与系统能力

本应用不申请相册、相机、存储、位置、通讯录等系统权限；安装包的权限清单里只有「网络」这一条。

· 选图：调起系统自带的图片选择器，应用只拿到你亲手选中的那几张图，拿不到整个相册；

· 保存：通过系统「保存控件」写入相册，由你在控件上点击触发一次性授权，同样不需要常驻权限；

· 网络：仅用于调用你自己配置的服务商接口。

5. 未成年人

本应用不面向不满 14 周岁的儿童。请勿添加未成年人照片，也不要让未成年人使用本应用生成他人形象。

6. 你的权利

你可以随时查看本机存了多少数据、一键清空全部记录（「我的 → 本机数据」），也可以直接卸载应用。我们没有你数据的副本，所以不存在「申请删除服务器副本」这一步——你只需要处理自己的手机和相册。

7. 购买会员时的支付信息

购买会员通过华为应用市场（IAP Kit）完成。支付、订单、退款全部由华为应用市场处理，我们不会接触到你的银行卡号、支付账号或订单明细，也拿不到你的华为账号资料。

本机只保存两条与会员有关的信息：是否已开通、到期时间。用于判断解锁状态，不上传。

会员状态随华为账号走，所以换机或重装后可以用「恢复购买」找回；免费体验额度是纯本机的，不随账号恢复。

8. 人脸照片（敏感个人信息）

人脸照片属于《个人信息保护法》规定的敏感个人信息。本应用只在两种情况下接触它：一是在本机做抠图与合成（不联网）；二是你点「开始生成」时，它随请求由手机直接发给你自己配置的服务商。

处理它的必要性在于：换装、换发型、证件照这三件事，没有人脸就无从生成。你不添加人脸照片，这些处理就不会发生——应用不会主动去读你的相册。

我们不用人脸照片做身份识别、不做特征分析、不用来训练模型，也不留存任何副本：本应用没有服务器，技术上也没有能力这样做。

按法律要求，处理敏感个人信息需要你单独同意。这项同意在首次启动时单独勾选，和「同意条款」分开；不勾选就无法使用需要人脸的合成功能。
