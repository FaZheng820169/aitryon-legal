1. 本应用是什么

本应用是一个在手机上本地运行的工具，不提供模型服务，也不设中转服务器：你在「我的」里填好某家 AI 服务商的接口地址和 API Key 后，图片由你的手机直接发给那家服务商，生成结果再直接回到手机上。你和该服务商之间的权利义务，适用其服务条款。

2. 使用前提

你需要自行准备服务商账号与 API Key，并自行承担由此产生的调用费用。本应用不代收模型调用费用，也不对服务商的可用性、额度、生成质量作出承诺。

3. 你承诺的事

· 你添加的人像、服装图片，你本人拥有权利，或已取得权利人的明确授权；

· 不使用他人肖像照片，尤其不使用未成年人、公众人物的照片做合成；

· 不添加身份证件、银行卡、病历等含敏感信息的图片；

· 不把生成结果用于冒充他人身份、诈骗、虚假宣传、色情或其他违法用途；

· 不用于伪造证件、签名、新闻现场等可能使公众误认的场景。

4. 内容责任

生成什么内容，取决于你添加的图片和你配置的提示词。这次传输由你的手机与服务商直接完成，本应用不参与，也没有能力查看传输内容，因此内容的合法性由你负责。因违反上述承诺产生的后果，由你自行承担。

5. 免责

生成结果由第三方模型产生，可能出现失真、错位、不符合预期的情况，仅供参考。因服务商故障、额度不足、网络中断造成的失败或损失，本应用不承担责任。

6. 生成结果怎么用

能不能商用，取决于三件事：你上传的人像、你用的服装图、以及模型服务商的条款。

· 人像：只能是你本人或已获授权的肖像。生成结果不得用于他人代言、虚假身份展示或任何使你或他人被误认的场景；

· 衣库服装：衣库里的服装图由本应用提供，服装款式与图片的权利归原权利人。用衣库服装生成的效果图，仅授权你在个人非商业范围内使用（自己保存、个人社交平台日常分享），不得用于电商详情页、广告投放、商品售卖、直播带货等商业用途，也不得转售或二次分发；

· 自行上传的服装：由你确保已获授权，能否商用按你与权利人的约定；

· 同时请遵守你所选模型服务商关于生成内容使用范围的约定。

需要把用衣库服装生成的效果图用于商业用途，请先联系我们取得书面授权。

7. 会员与内购

本应用提供买断制权益（一次性购买、永久有效、不自动续费，具体价格以应用内付费页展示为准），用于解锁当前已有的内置衣库与发型库素材、以及不限次生成与自定义上传。支付、订单、退款均由华为应用市场处理，具体规则见《会员服务协议》。买断不包含 AI 模型调用费用——那部分仍由你自行向服务商支付。

8. 条款更新

条款如有更新，会在应用内提示。不同意更新内容的，请停止使用并卸载本应用。
